# デザイントークン（JP 製品 LP）

目標: **現行ブランド印象を保ちつつ、製品 LP として美しい再構成**。ピクセル一致は不要。

## カラー

```css
:root {
  --ink: #262d4f;          /* ネイビー見出し */
  --ink-strong: #000000;
  --brand: #286ee6;        /* リンク・強調 */
  --cta: #ff4e13;          /* オレンジ CTA */
  --body: #3a3f4b;
  --muted: #7b7b7b;
  --bg: #fafbfc;
  --surface: #ffffff;
  --border: #d2d5db;
}
```

## タイポ

| 用途 | フォント | 代替理由 |
|------|----------|----------|
| 英字見出し | Red Hat Display | 現行と同じ Google Font |
| 日本語本文 | Noto Sans JP | TypeSquare 非依存 |
| 本文サイズ | 15–16px / line-height 1.7–1.8 | 読みやすさ優先 |

## レイアウト指針

- コンテナ最大幅: 約 1120–1200px
- セクション余白: デスクトップ 5–7rem、モバイル 3–4rem
- Hero: ブランド + 見出し + 短いリード + CTA 群 + 製品ビジュアル（1画面に詰めすぎない）
- CTA はオレンジを主役に。青はリンク・セカンダリ
- カード多用を避け、区切りは背景色の交互と余白で行う
- モーションは fade-in / hover 程度（2–3点）
